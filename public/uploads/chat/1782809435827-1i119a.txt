## ✨ Особенности

- **Три роли**: Клиент, Мастер, Владелец
- **Управление заказами**: создание, назначение, статусы
- **Чат в реальном времени**: общение по заказу
- **Темная тема**: стиль YouTube без красного цвета
- **Адаптивный дизайн**: работает на всех устройствах

### Роли и возможности

#### 👤 Клиент
- Создание заказов
- Просмотр истории заказов
- Чат с мастером
- Управление автомобилями

#### 🔧 Мастер
- Просмотр доступных заказов
- Принятие заказов в работу
- Обновление статусов
- Ведение лога работ

#### 👑 Владелец
- Полный контроль над заказами
- Назначение мастеров
- Управление персоналом
- Статистика и отчеты

## 🛠 Технологии

### Frontend
- **Next.js 14** - React фреймворк
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **Shadcn UI** - компоненты
- **Socket.io-client** - WebSocket

### Backend
- **Next.js API Routes** - бэкенд
- **Prisma** - ORM
- **PostgreSQL** - база данных
- **NextAuth.js** - аутентификация
- **Socket.io** - реал-тайм

### DevOps
- **VPS Beget** - хостинг
- **PM2** - управление процессами
- **Nginx** - веб-сервер
- **Docker** - контейнеризация
